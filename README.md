# NoteVault

Нативное приложение SwiftUI / Swift 6 / iOS 17+. Первая версия интерфейса и обычных заметок по предоставленному макету. Без платных зависимостей, регистрации, рекламы и сетевого хранения.

## Что работает в исходниках

- Главная, список и сетка заметок, редактор, поиск, настройки, корзина.
- Создание и редактирование обычных заметок, автосохранение каждого изменения в SwiftData, папки (поле в редакторе), теги, закрепление, избранное, перемещение в корзину и восстановление.
- Поиск по тексту, заголовку, папке и тегам; порядок по дате и закреплению, переключение направления.
- Экспорт обычных заметок в JSON через системный диалог. Экспорт не зашифрован.
- Светлая, тёмная и системная темы, системные шрифты, VoiceOver-подписи кнопок, адаптивная сетка, учёт Reduce Motion.
- Экран демоаккаунтов, карточка демоаккаунта, защищённая зона и пример связей. Сохранение настоящих паролей и секретных заметок отсутствует намеренно.
- Генератор использует SecRandomCopyBytes, отбрасывание смещённых значений и гарантирует присутствие выбранных классов символов. Копирование локальное, срок содержимого буфера — 30 секунд.

Редактор пока текстовый: кнопка заголовка вставляет Markdown-маркер, чек-лист — текстовые символы. Богатое форматирование, интерактивные чек-листы, фото, вложения и сканер ещё не реализованы. Иллюстрации из макета заменены SF Symbols: приложенный коллаж не содержит отдельных исходных фотографий.

## Бесплатная сборка без Mac

Смотрите [инструкцию для Windows](Docs/INSTALL_WINDOWS.md). Папку **NoteVault целиком используйте как корень репозитория**: `.github`, `App`, `Features` и `NoteVault.xcodeproj` должны оказаться непосредственно в корне. Включите показ скрытых файлов, чтобы не потерять `.github`.

Workflow создаёт неподписанный IPA только в публичном репозитории. Это не готовая установка: подпись бесплатным Apple ID выполняется отдельно на Windows. Никаких Apple ID, паролей, сертификатов или профилей в GitHub сохранять не нужно.

## Если появится Mac

Откройте `NoteVault.xcodeproj` в Xcode 16+ с Swift 6. Выберите схему NoteVault и iPhone Simulator (iOS 17+), затем Run. Для тестов — Product > Test. Для своего телефона требуется отдельная настройка подписи личной командой; исходники не содержат чужой команды разработчика.

## Архитектура

App — композиция зависимостей и навигация; DesignSystem — цвета и компоненты; Models — модели; Features — экраны и NotesViewModel; Services/Storage — протокол и реализации хранилища; Services/Crypto — только генератор. Services/Keychain зарезервирован под будущий модуль. Шифрование и Face ID не реализованы. Ошибка чтения блокирует перезапись исходных данных; ошибка записи не заменяет подтверждённое состояние.

Основное хранилище — SwiftData без CloudKit. JSON-репозиторий используется для независимого тестирования сохранения и обработки повреждений. Экспорт не является импортируемой резервной копией: импорт ещё нужно реализовать и проверить.
