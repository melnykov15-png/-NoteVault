# Сборка и установка с Windows без платного аккаунта

Проверено по официальным страницам 25 октября 2026 года. Установки на реальном iPhone в этой сессии не было. Версия iOS и модель iPhone пока неизвестны. Подтверждён публичный репозиторий melnykov15-png/-NoteVault. Приложение требует iOS 17+.

## 1. Условия GitHub Actions

Официальные страницы:
- https://docs.github.com/en/actions/concepts/billing-and-usage
- https://docs.github.com/en/billing/concepts/product-billing/github-actions
- https://docs.github.com/en/actions/reference/runners/github-hosted-runners

Стандартные GitHub-hosted runners, включая `macos-15`, бесплатны в публичных репозиториях. Larger runners платные и в проекте не используются. Стандартный macOS runner существует и для частных репозиториев, но там применяется квота тарифа и ограничения аккаунта/организации. На GitHub Free документация указывает 2000 включённых минут в месяц и 500 MB хранения артефактов, совместного с Packages. Эти 2000 минут нельзя считать 2000 фактическими минутами macOS: стоимость зависит от ОС. Актуальная страница billing указывает для стандартного macOS $0.062/мин вне включённых лимитов; проверять оставшуюся квоту нужно в Billing аккаунта. Старые советы о множителе x10 не следует использовать как обещание текущего остатка.

Ваш репозиторий melnykov15-png/-NoteVault подтверждён как публичный. Доступный остаток квоты аккаунта и страница Billing не проверялись; успешная сборка использовала стандартный runner публичного репозитория. Для гарантии отсутствия платных запусков подготовленный workflow **пропускает частные репозитории**. Для них сначала нужно проверить собственную квоту и блокирующий расходы бюджет, а затем отдельно изменить условие workflow. Ничего оплачивать или привязывать карту для этого проекта не требуется.

Артефакты хранятся один день; скачивайте их после сборки. Удаляйте ненужные артефакты, чтобы не заполнять доступное хранилище. Запуск ручной либо при изменении Swift-исходников, Xcode-проекта и workflow в main; максимум 25 минут на job. Изменения документации сборку не запускают.

## 2. Получить неподписанный IPA

1. Войдите в свой бесплатный GitHub-аккаунт и создайте публичный репозиторий. Исходники при этом будут общедоступны; личные заметки и секреты туда не загружайте.
2. Загрузите **содержимое** папки NoteVault в корень. В частности, путь workflow должен быть `.github/workflows/ios-build.yml`, проекта — `NoteVault.xcodeproj/project.pbxproj`. Для загрузки подойдёт GitHub Desktop или Git; после добавления проверьте наличие скрытой папки `.github` на сайте.
3. Откройте Actions. При необходимости разрешите workflows для репозитория. Выберите `Build unsigned iPhone app` > Run workflow.
4. Дождитесь зелёного результата. Сначала идут XCTest на доступном iPhone Simulator, затем сборка Release для настоящего iPhone без подписи. При ошибке скачайте журнал: успешной сборку считать нельзя.
5. Скачайте артефакт `NoteVault-unsigned-NOT-INSTALLABLE-UNTIL-SIGNED`. Распакуйте внешнюю ZIP-обёртку GitHub: внутри будет `NoteVault-unsigned.ipa`. Сам IPA распаковывать не нужно.

Внутри IPA находится `Payload/NoteVault.app`. Сертификата и provisioning profile нет. Просто открыть файл на iPhone для установки нельзя. Этот архив предназначен для последующей локальной подписи.

## 3. Основной вариант — Sideloadly на Windows

Источники: https://sideloadly.io/ и https://sideloadly.io/faq.html

Нужны Windows, iPhone с iOS 17+, USB-кабель, бесплатный Apple ID, доступ к Apple для авторизации и подписи. Mac и оплаченная Apple Developer Program не нужны. На Windows официальный сайт требует версии iTunes и iCloud с сайта Apple, а не Microsoft Store; скачивайте их по ссылкам официальной инструкции Sideloadly. Не удаляйте существующие компоненты без проверки, нужны ли они вам для других задач.

1. Скачайте Sideloadly только с официального сайта и установите нужные Apple-компоненты.
2. Подключите разблокированный iPhone по USB, подтвердите доверие к компьютеру на телефоне.
3. В Sideloadly выберите телефон и перетащите `NoteVault-unsigned.ipa`.
4. Введите бесплатный Apple ID в **локальное приложение Sideloadly**, пройдите запрошенную Apple авторизацию. Не отправляйте пароль в чат или GitHub Secrets. Используйте локальный Anisette, когда этот режим доступен; параметры авторизации и системные запросы проверяйте по официальной инструкции.
5. Запустите подпись/установку. Если iOS попросит доверять профилю разработчика, откройте Настройки > Основные > VPN и управление устройством и подтвердите свой профиль.
6. Если требуется Developer Mode: Настройки > Конфиденциальность и безопасность > Режим разработчика, затем выполните системные указания и перезагрузку.
7. Проверьте запуск приложения, создайте пробную обычную заметку, закройте и откройте приложение, убедитесь, что текст сохранился. Затем проверьте корзину и экспорт.

По официальной FAQ бесплатная подпись действует 7 дней, одновременно доступно до 3 приложений с бесплатной подписью; также возможен лимит 10 App ID за 7 дней. Для продления используйте тот же Apple ID и bundle ID, устанавливая поверх приложения. Не удаляйте приложение перед обновлением: это может удалить локальные заметки. Автообновление требует доступного компьютера с Sideloadly Daemon и USB либо настроенным Wi-Fi. Приложение работает офлайн после установки, но подпись и её продление требуют соединения с Apple.

Это реалистичный документированный путь, но совместимость вашей версии iOS и успешную подпись конкретной сборки подтвердит только фактическая установка. При ошибке не покупайте сертификат: сохраните текст ошибки и проверьте ограничения Apple ID, драйверы и актуальную FAQ.

## 4. Альтернатива — AltStore Classic + AltServer

Источники:
- https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows
- https://faq.altstore.io/altstore-classic/altserver
- https://faq.altstore.io/altstore-classic/your-altstore

Используйте **Classic**, а не AltStore PAL. AltServer работает на Windows; инструкция требует iTunes/iCloud из Apple и включения Developer Mode на iOS 16+. Установите AltServer, подключите iPhone, включите Wi-Fi sync, установите AltStore через значок AltServer с вашим Apple ID и доверьтесь своему профилю на телефоне. Затем в AltStore > My Apps > + выберите полученный IPA. Держите AltServer доступным по USB либо в той же Wi-Fi-сети для обновления.

Приложения также истекают через 7 дней. AltStore занимает одно из трёх доступных мест, поэтому для других приложений обычно остаётся два. Не чередуйте инструменты подписи без необходимости: изменения сертификатов могут потребовать обновить другие установленные приложения.

## Что здесь не предлагается

TestFlight и App Store не являются бесплатным способом распространения без Apple Developer Program. GitHub Codespaces сам по себе не предоставляет macOS/Xcode. Xcode Cloud не нужен для этого маршрута. Не нужны jailbreak, арендованный Mac, платные сертификаты или сервисы выдачи чужих профилей.
